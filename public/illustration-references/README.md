# Illustration style references

Reference copies of the four original half full reaction characters from `public/reactions/` (see that folder's README for the generation prompts and provenance), resampled from 192×192 to 768×768 PNG with macOS `sips` on October 24, 2026 because Recraft style creation requires every reference image to be at least 256 pixels on its shortest side. No other edits were made. These files define the reusable Recraft style recorded as `half-full-style/1` in `lib/illustration-style.ts`; the reader still uses the original optimized WebP stickers.
