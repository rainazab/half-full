# half full pigment

`half-full-pigment.png` is an original, deterministic 512 × 512 grayscale texture
generated by `node scripts/generate-pigment.mjs`. Its seeded high-frequency
stochastic samples are filtered on a torus and quantized to sixteen tiny tonal
steps. It has no designed grid, copied pixels, animated noise, or runtime filter.

The CSS renders one source pixel per CSS pixel by default, softly blends it with
the current color fields, and masks it away from the cleanest paper region.
The grain remains fixed while parent theme variables can follow a finger drag.
Use `scale={0.5}` for finer high-density detail or `scale={1}` for the normal
1-pixel pigment. Each instance reuses the same cacheable file.

Broad gradients and a small masked soft-light layer do the compositing work;
the video, controls, and text remain separate, sharp layers above the atmosphere.
